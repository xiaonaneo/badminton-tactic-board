# 羽毛球战术板

一个纯前端的羽毛球战术绘制工具，用于在场地上布置球员、羽毛球、箭头、画笔轨迹和文字标注。

## 功能

- 拖动红方、蓝方和羽毛球标记
- 绘制箭头与画笔轨迹
- 添加、移动和删除文字标注
- 撤回、清空和 PNG 保存
- 浏览器本地保存战术状态
- 手机端支持系统分享与微信粘贴回退

## 运行

进入项目目录后执行：

```bash
cd badminton-tactic-board
npm run dev
```

然后打开 `http://127.0.0.1:4173`。

项目也可以直接打开 `badminton-tactic-board/index.html` 使用。

## 技术栈

原生 HTML、CSS、JavaScript 和 SVG，无前端框架和构建依赖。
