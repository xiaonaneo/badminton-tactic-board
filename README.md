# 羽毛球战术板

一个无需构建、无需后端的纯前端羽毛球战术绘图工具。使用 SVG 绘制场地和战术元素，支持电脑与手机浏览器。

## 在线使用

- 生产站点：<https://badmintonmind.netlify.app>
- 最新正式版本：<https://github.com/xiaonaneo/badminton-tactic-board/releases/tag/v1.0.1>
- 首个正式版本：<https://github.com/xiaonaneo/badminton-tactic-board/releases/tag/v1.0.0>

## 功能

- 添加红方、蓝方和羽毛球标记，并拖动调整位置。
- 绘制黄色箭头和红色自由画笔轨迹。
- 添加、拖动和删除文字标注。
- 使用擦除工具直接移除场地上的元素。
- 撤回最近操作，或通过确认卡片清空全部战术。
- 自动保存到浏览器本地存储，刷新页面后可恢复。
- 将战术板生成 PNG：桌面端下载，移动端优先调用系统分享。
- 添加红方、蓝方或羽毛球后自动切换到移动工具，方便立即调整位置。
- 红方、蓝方和羽毛球添加时会自动避让已有标记，减少重叠。
- PC 端将工具栏与场地作为整体居中，移动端保持响应式侧边栏布局。
- 响应式布局适配 PC 和移动端，移动端保持紧凑的侧边栏按钮布局，按钮背景保持透明。
- 操作按钮点击时图标短暂显示品牌色，完成后自动恢复未点击状态。
- 使用荧光羽毛绿作为品牌强调色，支持联系作者与 GitHub 仓库入口；卡片在点击其他位置后自动关闭并恢复按钮状态。

## 快速开始

项目没有构建步骤，也没有运行时依赖。使用本地 HTTP 服务可以获得更稳定的分享和剪贴板行为：

```bash
cd badminton-tactic-board
npm run dev
```

然后打开 <http://127.0.0.1:4173>。

也可以直接打开 `index.html`，但部分浏览器能力可能受 `file://` 安全策略限制。

## 操作说明

| 工具 | 用途 |
| --- | --- |
| 移动 | 选择并拖动球员、羽毛球、箭头或文字标注 |
| 箭头 | 按住并拖动，绘制黄色线路 |
| 画笔 | 按住并拖动，绘制红色轨迹 |
| 标注 | 点击场地后输入文字，创建可拖动标注 |
| 撤回 | 移除最近添加的对象 |
| 擦除 | 点击场地上的元素将其移除；再次点击退出擦除模式，点击其他操作也会自动退出 |
| 清空 | 在确认卡片中确认后移除当前战术中的全部对象 |
| 分享战术 | 生成 PNG 并下载或调用系统分享 |

快捷键：`Cmd/Ctrl + Z` 撤回；`Delete` 或 `Backspace` 删除选中对象。

## 数据与分享

- 战术数据只保存在当前浏览器的 `localStorage` 中，不会自动上传服务器。
- 分享内容是生成后的 PNG 图片，不是可继续编辑的战术数据文件。
- 移动端是否能直接分享给指定好友，取决于浏览器、系统和目标应用对 Web Share 的支持。
- 注意：使用微信内置浏览器打开战术板时，“分享战术”无法由网页直接转发给指定微信好友。可先复制战术板网页链接，在 Safari、Chrome 等独立浏览器中打开并编辑，再使用系统分享转发；是否能选择指定微信好友仍取决于设备、浏览器和微信版本的支持。
- 如需在微信公众平台配置 JS 安全域名，可使用项目目录中的 `badminton-tactic-board/665e0d64c8f553b491eb23b7f64c75cb.txt` 完成域名验证。
- 清除浏览器站点数据会同时清除自动保存的战术状态。

## 场地模型

场地几何以米为唯一真实单位，使用 `SCALE = 50` 像素/米进行 SVG 渲染。当前绘制双打全场：

| 项目 | 数值 |
| --- | ---: |
| 全场长 | 13.40 m |
| 场地宽 | 6.10 m |
| 单打边线间距 | 5.18 m |
| 前发球线距网 | 1.98 m |
| 双打后发球线距端线 | 0.76 m |

## 项目结构

- `index.html`：页面结构、工具栏和按钮。
- `styles.css`：界面样式、响应式布局和交互状态。
- `court.js`：场地几何、坐标换算和 SVG 绘制。
- `app.js`：交互、对象管理、本地保存、PNG 生成和分享回退。
- `share-utils.js`：Web Share 能力检测和图片剪贴板回退。
- `manifest.json`、`icon.svg`、`icon-180.png`、`icon-512.png`：应用元数据和图标。
- `test/`：行为和样式回归测试。
