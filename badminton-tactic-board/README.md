# 羽毛球战术板（最小可跑原型）

无构建依赖：双击 `index.html` 即可在浏览器打开，或 `python3 -m http.server` 后访问。

## 场地尺寸与坐标映射

唯一真实尺寸来源是“米”，渲染时经 `SCALE = 50`（像素/米）统一换算，比例不失真。

| 项目 | 数值 |
| --- | --- |
| 全场长 | 13.40 m |
| 场地宽（双打） | 6.10 m |
| 前发球线距网 | 1.98 m |
| 双打后发球线距端线 | 0.76 m |

来源：BWF《羽毛球竞赛规则》(Laws of Badminton)。

## 文件

- `court.js`：场地几何与 SVG 绘制，`pxToMeters` / `metersToSvgPx` / `clampMeters` 是坐标换算入口。
- `app.js`：球员/羽毛球标记、箭头、标注的创建、拖拽、选中、删除，以及导出 PNG。
- `index.html` / `styles.css`：结构与样式。

## 功能与操作

- 工具「移动」：拖拽球员/羽毛球/标注；点击选中，选中后可用「删除选中」或 Delete 键移除。
- 工具「箭头」：在场地按住拖拽，画出带箭头头的线路。
- 工具「画笔」：在场地按住拖拽，自由绘制白色线条。
- 工具「标注」：点击场地后输入文字，生成可拖动的文字标注。
- 「导出 PNG」：把当前球场连同所有元素栅格化成 PNG 下载（内部先克隆 SVG、内联计算样式，再经 canvas 导出）。

## 技术选型说明

选 SVG 分两层（底层球场 + 顶层可拖标记），拖拽用 Pointer Events，坐标用 `getScreenCTM().inverse()` 反解到 SVG 内部坐标系，响应式缩放时标记不会漂移。相比 Canvas：线条任意缩放不失真、标记可直接用 DOM 事件拖拽、后续加箭头/标注/导出图片（`XMLSerializer` 序列化 SVG）更直接。若后续要迁到框架，`court.js` 的几何层可原样保留，仅把 `app.js` 的 DOM 操作换成 Vue3 / React 的响应式渲染。
