# 羽毛球战术板

一个无需构建、无需后端的纯前端羽毛球战术绘图工具。它使用 SVG 绘制场地和战术元素，适合在电脑或手机浏览器中快速布置站位、绘制线路并分享战术截图。

## 功能

- 添加红方、蓝方和羽毛球标记，并在场地上拖动调整位置。
- 绘制箭头线路和自由画笔轨迹。
- 添加、拖动和删除文字标注；选中的画笔轨迹会变为黄色。
- 撤回最近添加的对象、删除选中对象、清空全部战术。
- 自动将当前战术状态保存到浏览器本地存储，刷新页面后可恢复。
- 将场地和战术元素生成 PNG：
  - 桌面浏览器直接下载 PNG。
  - 支持文件分享的移动浏览器调用系统分享面板。
  - 分享能力受限时，先尝试复制图片到剪贴板，失败后下载 PNG。

## 快速开始

项目没有构建步骤，也没有运行时依赖。建议通过本地 HTTP 服务运行，以获得更稳定的移动端分享和浏览器行为：

```bash
cd badminton-tactic-board
npm run dev
```

然后打开 <http://127.0.0.1:4173>。

也可以直接打开 `index.html`，但部分浏览器能力（尤其是系统分享和剪贴板）可能受 `file://` 安全策略限制。

## 操作说明

| 工具或按钮 | 用途 |
| --- | --- |
| 移动 | 选择并拖动球员、羽毛球、箭头或文字标注 |
| 箭头 | 按住并拖动，绘制带箭头的线路 |
| 画笔 | 按住并拖动，自由绘制轨迹 |
| 标注 | 点击场地后输入文字，创建可拖动标注 |
| 撤回 | 移除最近添加的对象 |
| 删除 | 删除当前选中的对象 |
| 清空 | 移除当前战术中的全部对象 |
| 分享战术 | 生成 PNG 并下载或调用系统分享 |

快捷键：`Cmd/Ctrl + Z` 撤回；`Delete` 或 `Backspace` 删除选中对象。

## 数据与分享

- 战术数据只保存在当前浏览器的 `localStorage` 中，不会自动上传服务器。
- 分享的是生成后的 PNG 图片，不是可继续编辑的战术数据文件。
- 微信好友分享是否能直接进入指定会话，取决于当前浏览器、系统和微信对 Web Share 的支持；不支持时可使用“复制图片”后在微信中粘贴。
- 清除浏览器站点数据会同时清除自动保存的战术状态。

## 场地模型

场地几何以米为唯一真实单位，当前使用 `SCALE = 50` 像素/米进行 SVG 渲染。双打全场尺寸如下：

| 项目 | 数值 |
| --- | ---: |
| 全场长 | 13.40 m |
| 场地宽 | 6.10 m |
| 前发球线距网 | 1.98 m |
| 双打后发球线距端线 | 0.76 m |

几何尺寸参考 BWF《羽毛球竞赛规则》（Laws of Badminton）。

## 项目结构

- `index.html`：页面结构、工具栏和按钮。
- `styles.css`：透明毛玻璃界面、响应式布局、状态和光标样式。
- `court.js`：场地几何、坐标换算和 SVG 场地绘制。
- `app.js`：交互、对象创建与拖动、本地保存、PNG 生成和分享回退。
- `share-utils.js`：Web Share 能力检测和图片剪贴板回退。
- `manifest.json`、`icon.svg`、`icon-180.png`、`icon-512.png`：应用元数据和图标。
- `test/`：分享、选中状态、标注样式、图标布局、圆角场地和操作分组测试。
